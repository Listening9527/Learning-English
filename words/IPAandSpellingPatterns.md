# 国际音标（IPA）与英语拼写组合总表

说明：
- 本表按“音标 -> 常见字母/字母组合（graphemes）”整理。
- 英语并非完全规则拼写系统，所谓“全部组合”在理论上无限扩展。本文档覆盖现代英语中主流、可教学、可考试的高频组合，并补充常见例外。
- 口音差异（英式/美式）会影响个别音值，本表以通用学习体系为主。

## 4. 词尾规则（必须掌握）

### 复数/三单 -s, -es
- /s/：清辅音后（cats /kæts/【猫（复数）】, books /bʊks/【书（复数）】, cups /kʌps/【杯子（复数）】, maps /mæps/【地图（复数）】, laughs /lɑːfs/【笑（三单）】）
- /z/：浊辅音和元音后（dogs /dɒɡz/【狗（复数）】, plays /pleɪz/【玩/播放（三单）】, bags /bæɡz/【袋子（复数）】, pens /penz/【钢笔（复数）】, cars /kɑːrz/【汽车（复数）】）
- /ɪz/：s, z, ʃ, ʒ, tʃ, dʒ 后（washes /ˈwɒʃɪz/【洗（三单）】, sizes /ˈsaɪzɪz/【尺寸（复数）】, watches /ˈwɒtʃɪz/【看/手表（三单/复数）】, bridges /ˈbrɪdʒɪz/【桥（复数）】, buses /ˈbʌsɪz/【公共汽车（复数）】）

### 过去式 -ed
- /t/：清辅音后（worked /wɜːkt/【工作（过去式）】, watched /wɒtʃt/【观看（过去式）】, laughed /lɑːft/【大笑（过去式）】, helped /helpt/【帮助（过去式）】, kissed /kɪst/【亲吻（过去式）】）
- /d/：浊辅音和元音后（played /pleɪd/【玩（过去式）】, cleaned /kliːnd/【打扫（过去式）】, opened /ˈəʊpənd/【打开（过去式）】, lived /lɪvd/【居住（过去式）】, called /kɔːld/【打电话（过去式）】）
- /ɪd/：/t/ 或 /d/ 后（wanted /ˈwɒntɪd/【想要（过去式）】, needed /ˈniːdɪd/【需要（过去式）】, started /ˈstɑːtɪd/【开始（过去式）】, decided /dɪˈsaɪdɪd/【决定（过去式）】, invited /ɪnˈvaɪtɪd/【邀请（过去式）】）

## 5. 高频“同拼写多发音”提醒

- ea -> /iː/（sea /siː/【n. 海】）, /e/（head /hed/【n. 头】）, /eɪ/（great /ɡreɪt/【adj. 伟大的】）
- oo -> /uː/（food /fuːd/【n. 食物】）, /ʊ/（book /bʊk/【n. 书】）, /ʌ/（blood /blʌd/【n. 血液】）
- ow -> /oʊ/（snow /snəʊ/【n. 雪】）, /aʊ/（cow /kaʊ/【n. 母牛】）
- ou -> /aʊ/（out /aʊt/【adv. 在外面】）, /ʌ/（young /jʌŋ/【adj. 年轻的】）, /uː/（group /ɡruːp/【n. 小组】）, /ɔː/（four /fɔːr/【num. 四】）
- ch -> /tʃ/（chair /tʃeər/【n. 椅子】）, /k/（school /skuːl/【n. 学校】）, /ʃ/（machine /məˈʃiːn/【n. 机器】）
- th -> /θ/（think /θɪŋk/【v. 想】）, /ð/（this /ðɪs/【pron. 这个】）
- c -> /k/（cat /kæt/【n. 猫】）, /s/（city /ˈsɪti/【n. 城市】）
- g -> /g/（go /ɡəʊ/【v. 去】）, /dʒ/（giant /ˈdʒaɪənt/【n. 巨人】）

## 6. 学习顺序建议（从实用出发）

1.先掌握 20 个核心元音音值（含双元音）
2. 再掌握高频辅音及清浊对立
3. 把 -s/-ed 词尾规则练到自动化
4. 专练多发音组合（ea, oo, ow, ou, ch, th）
5. 结合重音与弱读做句子跟读

## 7. 备注：关于“全部组合”

- 如果按词典穷举，组合会随外来词、人名、地名持续增加。
- 如果按教学语音学，本表已覆盖主流体系中应掌握的拼写-音标对应关系。
- 真正提升拼读准确率的关键，不是继续扩展低频特例，而是高频规则 + 例外词反复复现。

## 7. 连读技巧整理

说明：
- 连读的核心目标是“更自然、更省力”，不是把每个词都读得更快。
- 连读优先出现在意群内部（同一语块中），停顿处一般不连。
- 本节统一采用美音（General American）示例。

### 7.1 辅音 + 元音（最常见）

- 规则：前词尾是辅音，后词首是元音时，辅音会自然“带到”后一个词。
- 例子：
  1.pick it up -> /ˈpɪkɪtʌp/（听感接近“pi-ki-tup”）
  2.take it easy -> /ˈteɪkɪt ˈiːzi/
  3.turn off -> /tɝnɔf/
  4.find out -> /faɪndaʊt/
  5.leave it -> /ˈliːvɪt/

### 7.2 辅音 + 辅音（同化/失去爆破）

- 规则 A：相邻发音部位接近时，前一个音可能被同化。
- 常见：
  1.good boy -> /ɡʊb bɔɪ/（/d/ 向 /b/ 靠近）
  2.good girl -> /ɡʊɡ ɡɝl/（/d/ 向 /ɡ/ 靠近）
  3.ten boys -> /tem bɔɪz/（/n/ 常听成 /m/）

- 规则 B：爆破音相邻时，前一个爆破常“只做口型不爆破”。
- 常见：
  1.big cat（/ɡ/ 常弱爆破）
  2.not bad（/t/ 常弱爆破）
  3.last time（/t/ 常弱爆破）

### 7.3 元音 + 元音（加过渡音）

- 规则：两个元音相遇时，为避免断裂，常加入 /j/ 或 /w/ 过渡。
- /j/ 过渡（前一个音偏前高，如 /iː, ɪ, eɪ/）：
  1.see it -> /siːjɪt/
  2.we are -> /wiːjɑr/
  3.I agree（中间常有轻微过渡）
- /w/ 过渡（前一个音偏后圆唇，如 /uː, oʊ, aʊ/）：
  1.go out -> /ɡoʊwaʊt/
  2.do it -> /duːwɪt/
  3.you are -> /juːwɑr/

### 7.4 /t/ 的常见口语变化（美音）

- 闪音 /ɾ/（类似轻快的“d”）：
  1.water -> /ˈwɔɾɚ/
  2.better -> /ˈbɛɾɚ/
  3.city -> /ˈsɪɾi/
- /t/ + /j/ -> /tʃ/：
  1.don't you -> /doʊntʃuː/
  2.can't you -> /kæntʃuː/
- /d/ + /j/ -> /dʒ/：
  1.did you -> /dɪdʒuː/
  2.would you -> /wʊdʒuː/

### 7.5 h-弱化（功能词）

- 规则：he, him, her, his 等在非重读位置，/h/ 常弱化或脱落。
- 例子：
  1.tell him -> /tel ɪm/
  2.ask her -> /æsk ɚ/
  3.find him -> /faɪnd ɪm/

### 7.6 高频缩读（和连读一起出现）

- going to -> gonna（/ˈɡʌnə/）
- want to -> wanna（/ˈwɑnə/）
- got to -> gotta（/ˈɡɑɾə/）
- kind of -> kinda（/ˈkaɪndə/）
- give me -> gimme（/ˈɡɪmi/）
- let me -> lemme（/ˈlemi/）

提示：缩读适合口语听说，不建议直接用于正式写作。

### 7.7 常见易错点

- 易错 1：把 every word 都连起来，导致句子无层次。
- 易错 2：忽略重读词，结果“快但不清楚”。
- 易错 3：音标写法混用（如英音 /əʊ/ 与美音 /oʊ/），导致自己读得不稳定。
- 易错 4：只学缩读拼写，不练真实语流。

### 7.8 实操训练法（建议 10-15 分钟/天）

1. 选 2 句短句（8-12 词），先慢速标出连读点。
2. 跟读原音 3 遍，只模仿节奏和停顿。
3. 再跟读 5 遍，重点做辅音-元音连读。
4. 最后录音对比：是否“重读词清楚、功能词自然弱读”。

推荐短句：
- Pick it up and put it on.
- Did you see it?
- I want to go out.
- Tell him I can do it.
- We are in a good place now.

### 7.9 还可补充的高频弱读词（美音口语很关键）

- to：常弱读为 /tə/（如 want to /ˈwɑnə/）
- for：常弱读为 /fɚ/（如 for a minute -> /fɚ ə ˈmɪnɪt/）
- of：常弱读为 /əv/ 或 /v/（a lot of it -> /ə ˈlɑɾəv ɪt/）
- and：常弱读为 /ən/ 或 /n/（bread and butter -> /ˌbrɛd ən ˈbʌɾɚ/）
- can（肯定）：常弱读 /kən/；否定 can't 保留重读（避免听感混淆）

提示：连读效果很大一部分来自“功能词弱读 + 内容词重读”。

### 7.10 常见省音（Elision）补充

- /nt/ 在快读中常弱化：
  1.center -> /ˈsɛnɚ/
  2.internet -> /ˈɪnɚˌnɛt/（口语常见）
- /t/ 或 /d/ 在辅音群中可弱化或省略：
  1.next day -> /nɛks deɪ/
  2.old friend -> /oʊl frɛnd/
  3.must be -> /mʌs bi/

提示：省音是“可懂度优先”的自然现象，不建议为省而省。

### 7.11 最小自检清单（每次跟读后 30 秒）

1. 我是否保留了句子重读词（名词、动词、形容词）？
2. 功能词是否有弱读（to, for, of, and, him, her）？
3. 边界处是否做了至少 1-2 个自然连读（辅音+元音或 /j,w/ 过渡）？
4. 语速变快后，是否仍然清楚可懂？

结论：
- 连读不是独立技巧，而是“重音 + 弱读 + 节奏”共同作用的结果。
- 先保证清晰，再追求速度；先练高频句型，再扩展到自由表达。
