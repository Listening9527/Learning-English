## 严格词根学判定规则

| 类型 | 判定标准 | 示例 |
| - | - | - |
| 派生词 | 在词根/词干上添加前缀或后缀形成新词 | unhappy, kindness |
| 复合词 | 两个或以上自由词素直接组合 | pushover, toothpaste |
| 转化词 | 词形不变，仅词性变化 | bottle (n.) -> bottle (v.) |
| 缩略/拼缀词 | 截短或拼接形成新词 | lab, brunch |
